## Gotchas
- Never confirm a booking from the browser's Razorpay success callback.
- Razorpay webhook needs the **raw** request body for signature; do not mount JSON parser before it on that route.
- `ceil` for advance, not `round`.
- Staff time overlap must be enforced by the DB, not just app code.
- `VITE_` env vars are public. Never put keys there.
- WhatsApp marketing templates need approval and opt-in; transactional ones for booking events only.
- India numbering: ₹1,25,000 not ₹125,000.
- Existing demo seed credentials must be changed in any deployed environment.
- Ledger is append-only. Never UPDATE/DELETE money rows; use `adjustment`.
- Do NOT copy the reference's "0% commission" copy anywhere; we charge commission.
- Payout job must be idempotent and never block on one failing salon.
- Never store full bank account number or PAN; only RazorpayX ids + last4.
